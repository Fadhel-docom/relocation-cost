# Relocation Cost

A production-first relocation cost planning suite.

## MVP

- Astro + Tailwind
- Responsive homepage
- Moving cost calculator using distance, home size, and move type
- SEO guide pages
- Static build suitable for Cloudflare Pages

## Local development

```bash
npm install
npm run dev
```

The calculator is intentionally presented as a planning estimate rather than a quote. Its coefficients are placeholders for the MVP and should be replaced with validated market data as the product expands.
