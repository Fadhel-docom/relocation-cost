## Evaluation method
Scores are directional editorial-fit judgments, not measured acceptance probabilities. I checked the public page and asked: (1) does it discuss moving cost, relocation packages or budgeting? (2) could the current calculator add something distinct? (3) is the audience a plausible user? (4) is the page likely to be constrained by an existing vendor/tool or institutional policy? I did **not** verify external-link policies, editorial contact routes or willingness to accept third-party tools.

## Stop/go rules before any outreach
- These are drafts only. **No message has been sent.** Owner approval is required before any external contact.
- Before sending, verify the recipient/editor and the site's current submission or external-link policy. Do not guess an email address or scrape contacts.
- Offer a tool only if the live production version remains useful, accurate, mobile-usable and transparent about assumptions. A draft pitch is not evidence of demand.
- No paid placement, reciprocal-link demand, keyword-rich anchor request, mass outreach or unsupported audience/traffic claim.
- Track only if approved: one personalised contact per publisher, reply, review request, accepted placement and qualified referral use. Stop if there is no real user value.
- If a publisher already has a quote or estimator widget (Rent.com, WHR, ARC), treat it as a competitor/possible integration partner, not a default backlink target.
